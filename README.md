
### ✈️ Airline Delay & Cancellation Analysis — Excel

**Project Description**

Analyzed airline flight data using **Microsoft Excel** to identify patterns and trends in flight delays and cancellations. Cleaned and organized the dataset, performed data analysis using formulas and lookup functions, and created interactive dashboards using **Pivot Tables, Pivot Charts, and Slicers**.

**Key Features**

* Cleaned and prepared the airline dataset for analysis using Excel.
* Analyzed **flight delays, cancellations, airline performance, and causes of delays**.
* Used **XLOOKUP, IF, COUNTIF/COUNTIFS, SUMIF/SUMIFS, and other Excel functions** for data analysis.
* Created **Pivot Tables and Pivot Charts** to summarize key performance metrics.
* Added **Slicers** for interactive filtering by airline, airport, month, cancellation reason, and other categories.
* Developed an interactive **Excel dashboard** to visualize important trends and insights.
* Identified airlines, routes, and time periods with higher delay and cancellation rates.
* Used data-driven insights to compare airline performance and understand major contributors to delays.
